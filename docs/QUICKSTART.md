# 시작하기

[README로 돌아가기](../README.md)

## 1. 준비

- Python 3.10 이상: `python3 --version`으로 확인합니다.
- WebGL을 지원하는 브라우저를 사용합니다.
- 이 저장소를 내려받고 폴더로 이동합니다. 비공개 저장소이면 GitHub 접근 권한이 필요합니다.
- Python 표준 라이브러리만으로 실행하므로 별도의 `pip install` 없이 시작할 수 있습니다. 브라우저 라이브러리는 `simulator/static/vendor/`에 포함되어 있습니다.

## 2. 서버 실행

```bash
cd serbot-agv-simulator
python3 -m simulator.server
```

서버가 출력하는 주소 <http://127.0.0.1:8767>을 브라우저에서 엽니다. 서버 터미널은 실행된 채로 둡니다. Windows에서는 `py -m simulator.server`도 가능합니다.

**HTML 파일을 더블클릭해서 열지 않습니다.** `file://` 주소로 열면 Python API와 연결되지 않습니다.

포트를 바꾸려면:

```bash
python3 -m simulator.server --port 8770
```

이때 브라우저 주소는 `http://127.0.0.1:8770`입니다. Python AI에도 `SimRobot('http://127.0.0.1:8770')`으로 같은 주소를 지정합니다.

## 3. 화면에서 확인

1. 게임 시작 전에 아이 수와 배속을 정합니다.
2. 놀이 선택에서 **술래잡기**, **로봇 자동 추격**을 선택하고 **게임 시작**을 누릅니다.
3. 아이들은 로봇과의 거리에 따라 걷기·조깅·달리기로 바꾸며 벽과 다른 아이를 피합니다.
4. 잡힌 아이는 붉은 표시와 함께 멈춥니다. 모두 잡히면 게임이 끝납니다.
5. 수동 버튼이나 Python 주행 명령을 사용하면 자동 추격이 해제됩니다. 체크박스로 다시 켤 수 있습니다.
6. 기존 **무궁화꽃이 피었습니다**를 선택하면 로봇 전방에서 정지, 뒤쪽에서 접근, 터치 후 전원 도망 규칙을 사용합니다.

게임 중 인원 변경은 막혀 있습니다. **환경 초기화** 후 변경하세요. **새 게임**은 위치·시간·진행 중인 명령·카메라 프레임을 초기화하고, 인원과 배속은 유지합니다.

화면 상단 **일시정지**는 가상 세계 시간을 멈춥니다. **놀이 잠깐 멈춤**은 참가자 이동만 멈춥니다. **로봇 정지**는 로봇의 주행 명령과 자동 추격을 중단합니다.

화면에 **ChildACT 동작 연결됨**이 표시되면 데이터에서 변환한 관절 동작을 사용합니다. 준비 방법은 [ChildACT 연결](CHILDACT.md)을 확인하세요. 이동 경로는 시뮬레이터가 생성하며 실제 어린이의 실측 궤적은 아닙니다.

## 4. Python 입출력 확인

서버와 브라우저를 유지하고, 두 번째 터미널에서 저장소 폴더로 이동해 실행합니다.

```bash
python3 -m simulator.examples.camera_client
```

가상 카메라 정보를 출력하고 `artifacts/simulator/robot-camera.jpg`를 저장합니다. 실제 카메라나 실제 로봇에 연결하지 않습니다.

## 5. 선택: 다른 폴더의 AI 프로젝트에서 import

이 저장소 밖에서 `simulator`를 import하려면, **AI 프로젝트가 사용하는 Python 환경에** 편집 가능한 패키지로 설치할 수 있습니다.

```bash
python3 -m pip install -e /absolute/path/to/serbot-agv-simulator
```

경로는 자신의 실제 다운로드 위치로 바꿉니다. 설치 시 빌드 도구(setuptools)가 없으면 인터넷 다운로드가 필요할 수 있습니다. 설치 후에는 `serbot-sim` 명령으로 서버를 시작할 수도 있습니다.

서버와 AI는 별도 프로세스입니다. AI는 이미 실행 중인 서버의 HTTP API에 연결합니다. 자신의 AI를 시뮬레이터 웹 화면에 업로드할 필요는 없습니다.

## 문제 해결

| 증상 | 확인할 점 |
|---|---|
| `No module named simulator` | 저장소 루트에서 실행했는지, 다른 프로젝트라면 같은 Python 환경에 `pip install -e`했는지 확인합니다. |
| 브라우저가 연결되지 않음 | 서버 터미널이 살아 있는지와 포트가 맞는지 확인합니다. HTML 파일 대신 HTTP 주소를 엽니다. |
| `Address already in use` | 같은 포트의 서버가 이미 실행 중일 수 있습니다. 기존 터미널에서 종료하거나 다른 포트를 사용합니다. |
| 카메라 `503` | 시뮬레이터 탭을 활성화하고 영상이 LIVE가 되는지 확인합니다. 초기화 직후에는 새 프레임까지 잠깐 기다립니다. |
| 브라우저를 최소화하면 영상 중단 | 브라우저가 백그라운드 렌더링을 제한할 수 있습니다. 탭을 활성 상태로 유지합니다. |
| 게임 시작 후 아이들이 안 움직임 | 술래잡기에서는 잡힘·일시정지·놀이 멈춤을 확인합니다. 무궁화꽃이 피었습니다에서는 로봇 전방에 있으면 정상입니다. |
| 회전 중 일부만 움직임 | 아이별로 로봇과의 상대 방향을 판정하므로 전방과 뒤쪽에 나뉘면 서로 다르게 반응합니다. |
| 아이들이 멈춰 있었는데 갑자기 전원 도망 | 다른 아이가 술래를 터치하면 전원이 도망가는 규칙입니다. 로그에서 터치한 아이를 확인합니다. |
| Python 명령 대기 시간 초과 | 세계 일시정지나 느린 배속을 확인합니다. 기본 명령 대기는 실제 시간 130초입니다. |
| 3D 화면이 시작되지 않음 | 브라우저의 WebGL 지원과 하드웨어 가속을 확인합니다. 최신 브라우저에서 다시 엽니다. |

서버 종료는 서버 터미널의 `Ctrl+C`입니다. 서버나 JavaScript를 수정했다면 서버 재시작 또는 브라우저 새로고침이 필요합니다.
