# 무궁화꽃 친화형 술래

무궁화꽃 화면에서 **로봇 자동 제어**를 켜고 **시선 전환 시점 → 친화형 술래 · 학습 모델 → 게임 시작**을 선택한다. **놀이 소리**를 켜면 모델이 고른 세기로 구호와 정지 신호를 들을 수 있다. 게임 전후에는 인사, 음악, 마무리 동작을 재생하지 않는다. [학습 가중치](../../simulator/models/friendly_referee_v1.json)

| 접근 중 관찰 예시 | 등을 돌린 뒤 대기 | 돌아본 뒤 대기 | 구호 음량 배율 |
|---|---:|---:|---:|
| 5m 거리, 0.25m/s로 걷는 3명 | 4.60초 | 1.42초 | 0.93 |
| 6m 거리, 0.90m/s로 걷는 3명 | 2.60초 | 1.88초 | 0.99 |
| 1.05~1.50m에 모인 4명, 0.60~0.70m/s | 2.40초 | 2.08초 | 0.68 |

표는 가중치에서 직접 얻은 출력이다. 대기는 회전을 마치고 멈춘 시각부터 센다. 음량 배율은 WAV 파형의 진폭에 적용한다. 실제 공간에서 들리는 크기는 스피커 볼륨과 환경에 따라 달라진다.

## 한 판에서 하는 일

- 접근 중에는 현재 보이는 참가자들의 거리, 인원과 이동이 허용된 구간에서 측정한 속도를 사용한다. 참가자가 정지 신호를 지켜 서 있는 시간은 보행 속도 추정에서 제외한다. 한 번 정한 대기를 해당 자세가 끝날 때까지 유지한다.
- 부드러운 회전과 정지는 기존 주행기가 실행한다. 브라우저의 구호와 정지음은 실제 몸 방향이 바뀔 때 재생한다. 적발·호송과 터치 뒤 추격은 기존 게임 규칙이 진행하며, 모델은 놀이 중 효과음의 세기를 참가자 거리에 맞춘다.
- 검출이 모두 사라지거나 외부 검출이 0.5초보다 오래되면 새 움직임과 소리를 보류한다. 게임 종료 시 진행 중인 신호를 끊는다. 화면의 기본 관측은 가상 참가자의 좌표다. 실제 카메라 영상에서 참가자를 찾는 기능은 별도로 연결해야 한다.

## 학습과 평가

가상 참가자마다 출발 지연, 보행 속도, 멈추는 데 걸리는 시간과 거리를 생성했다. 각 장면에서 여러 대기시간과 음량을 비교해 보행 기회, 가까운 참가자에게 과도한 접근을 유도하는 정도, 정지 여유, 거리별 목표 음량을 점수화했다. 이 점수로 선택한 동작을 작은 신경망에 지도학습했다. 실제 아이가 느끼는 친근함을 측정한 데이터는 사용하지 않았다. [학습 코드](../../simulator/examples/train_friendly.py)

- 학습 9,000장면과 검증 1,200장면을 서로 다른 시드로 생성했다. 100회 학습 중 검증 오차가 가장 낮은 85번째 가중치를 저장했다.
- 새로운 조합 1,800장면에는 느린 아이와 빠른 아이가 함께 움직이거나, 가까운 무리가 일부 가려지거나, 여러 아이가 시차를 두고 출발하는 상황이 들어 있다. 고정 대기·음량과 비교한 평균 보행 기회 비용은 1.286에서 0.880, 정지 여유 비용은 0.158에서 0.143, 음량 비용은 0.0500에서 0.0014로 줄었다. 각 비용은 설계한 기준으로 계산하며 낮을수록 좋다.
- 별도로 3·6·8명, 조심형·활발형·도움형, 즉시·지연 정지, 두 평가용 배치에서 30개의 판을 구성했다. 각 판을 같은 초기 상태에서 세 제어기로 진행해 총 90판을 비교했다. 판당 최대 120초, 물리 간격 0.02초, 제어 간격 0.1초를 썼다. [평가 코드](../../simulator/examples/evaluate_friendly.py) · [학습 결과](friendly-results/training.json) · [판별 평가 기록](friendly-results/games.json)

| 30판 기준 | 술래 역할 완주 | 0.8m 이내 평균 시간 | 평균 각속도 변화량 합계 |
|---|---:|---:|---:|
| 기존 기본 규칙 | 29/30 | 5.84초 | 57.78rad/s |
| 같은 부드러운 회전과 고정 대기 | 26/30 | 13.29초 | 32.94rad/s |
| 학습 모델 | 29/30 | 2.83초 | 30.12rad/s |

완주는 전진 기회 뒤 유효한 정지 확인, 필요한 호송·복귀, 이후 추격이나 전원 탈락까지 진행한 판이다. 학습 모델에서 기준을 놓친 한 판은 활발형 6명이 모인 장면(시드 73119)이었다. 첫 유효 정지 확인 전에 아이가 술래를 터치해 곧바로 추격으로 넘어갔다. 각속도 변화량 합계는 한 판 전체의 변화로, 추격 길이와 회전 횟수의 영향도 받는다. [완주 정의](../../simulator/evaluate.py)

## 재실행 및 실물 연결

기본 Python만으로 저장한 가중치를 불러온다. 재학습에는 PyTorch와 NumPy가 필요하다. 아래 재학습 명령은 비교용 가중치를 별도 경로에 저장한다. 전체 판 평가 명령은 배포된 기본 가중치를 사용한다.

```bash
python3 -m simulator.server

# 브라우저 없이 저장한 모델로 한 판 진행
python3 -m simulator.examples.controller_client --game red_light --controller simulator.friendly_controller:FriendlyReferee --time-limit 120

# 재학습과 전체 판 평가
python3 -m simulator.examples.train_friendly --model artifacts/friendly/retrained.json --report artifacts/friendly/retrained-report.json
python3 -m simulator.examples.evaluate_friendly --output artifacts/friendly/games.json
```

실물 제어 쪽에서도 같은 가중치를 읽는다. 참가자별 입력은 로봇까지의 거리(m)와 최근 접근 구간의 보행 속도(m/s)다. 첫 관찰에서는 속도를 `None`으로 전달한다.

```python
from simulator.friendly_policy import FriendlyPolicy

policy = FriendlyPolicy()
choice = policy.decide('approaching', False, [(5.0, 0.25)] * 3)
# {'away_seconds': 4.6, 'watch_seconds': 1.42..., 'cue_gain': 0.93...}
```

Jetson 연결 함수 `run_cycle`은 실제 로봇 저장소의 `serbot_control.red_light.perform_cycle`을 호출한다. 로봇이 아이들을 향해 정지한 상태에서 호출하면, 보정된 회전 시간으로 한 번 돌아서고 돌아보며 각 신호와 대기에 모델 출력을 적용한다. 실행 중에는 호출자가 전달한 게임 상태, 추적 시각과 참가자 목록을 확인한다. 일시정지·종료·검출 소실·호송 또는 추격 전환 시 진행 중인 회차를 끊고 정지한다. 중간에 멈춘 경우 다음 회차 전에 로봇의 방향을 다시 확인해야 한다. [실물 연결 함수와 입력 형식](../../simulator/examples/friendly_jetson.py)

브라우저에서 가중치를 선택해 구호·정지음이 차례로 재생되고 종료 시 소리가 끊기는 것을 확인했다. 실제 로봇 저장소의 회전·스피커 코드와 모의 입출력을 연결해 한 회차, 구호 도중 종료, 이미 끝난 판을 확인했다. 실물 배포, 카메라 추적 입력 연결, 회전 시간 보정과 실제 스피커·아이 반응 검증은 남아 있다.
