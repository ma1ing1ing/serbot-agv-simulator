# 술래잡기 후속 실험 · 2026-11-22

기본 제어기는 `rule`을 유지한다. 접근 속도로 표적을 고르는 후보는 개발 10판과 새 평가 10판에서 기준과 같은 결과를 냈다. PPO는 두 보상 설정과 규칙 행동 모방 초기화 모두에서 학습 중 포획을 한 번도 경험하지 못했다.

세 실험은 `tag`, `open`, `oracle`, 아이 5명, 30초, 제어 간격 0.1초, 물리 간격 0.02초로 진행했다. 출발 커밋은 `8b9c338`, 최종 측정의 시뮬레이터 코드 해시는 `2fd41cc9dbf2`(SHA-256 접두사)다. 관측 계약 v1과 게임 규칙 `play-rules-2`를 사용했다. [기존 기준값과 평가 지표](TAG_EXPERIMENTS.md)

## 1. 첫 포획 전의 거리 변화

모든 판에서 마지막으로 고른 표적과 처음 잡힌 아이가 일치했다. 아래 거리 변화는 그 표적으로 전환한 순간부터 포획 순간까지의 중심 거리다. 연속 감소 구간은 0.1초마다 측정한 거리가 직전보다 작았던 최장 구간이며, 포획 순간은 물리 이벤트 시각을 썼다. 원시 기록에는 첫 표적부터 모든 추격 구간이 있다.

## 2. 접근 속도로 고른 표적과 기준 제어기 비교

`ClosingTagController`는 기준 제어기의 0.3m 전환 조건을 통과하고, 가장 가까운 후보와 거리 차이가 0.3m 이내인 대상끼리 비교한다. 최근 1초 동안 거리가 가장 많이 줄어든 대상을 우선한다. 거리 이력이 1초 미만이거나 거리가 줄어든 후보가 없으면 기준 제어기의 선택을 따른다. 조준점, 주행, 장애물 회피는 기존 코드를 공유한다. [제어기 구현](../simulator/examples/tag_pursuit.py)

## 3. PPO 학습에서 실제로 받은 포획 보상

학습 시드 72로 설정당 PPO 16,384단계를 실행했다. 한 판에 한 단계 이상 행동하면 시작 판에 포함했다. 세 모델은 각각 54판을 마치고 55번째 판에서 예산을 소진했다. `catch` 이벤트 1건이 포획 보상 +1에 해당하므로 같은 단계에서 두 명을 잡으면 2건으로 집계한다. 평가에서는 저장 모델을 다시 불러와 기존 평가 시드 21000–21009에서 결정적 행동을 사용했다.

| 학습 설정 | 시작 / 종료 판 | 학습 포획 이벤트 | 포획한 학습 판 | 학습 막힘 | 평가 포획 | 평가 전원 포획 | 평가 근접 단계/판 | 평가 회전 변화/판(rad/s) | 평가 막힘/판 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 막힘 감점 0.05 | 55 / 54 | 0 | 0/55 | 72 | 0/50 | 0/10 | 0.0 | 2.35 | 0.0 |
| 막힘 감점 0.10 | 55 / 54 | 0 | 0/55 | 70 | 0/50 | 0/10 | 0.0 | 6.07 | 0.0 |
| 규칙 행동 모방 후 감점 0.05 | 55 / 54 | 0 | 0/55 | 102 | 0/50 | 0/10 | 0.0 | 25.36 | 0.0 |
| 같은 평가 시드의 `rule` | — | — | — | — | 10/50 | 0/10 | 166.7 | 26.03 | 1.1 |

두 기본 실험 모두 학습 중 포획이 없어서, 별도 시드 51000–51009에서 `rule`의 관측·행동 3,000쌍을 수집했다. 시범 10판에는 포획 10건이 있었다. 행동 축별 최대 속도로 정규화한 평균제곱오차를 최소화하도록 정책을 8에포크 학습했다(배치 64, Adam 학습률 0.001). 그 가중치에서 기존 설정으로 PPO 학습을 시작했다. 시범 포획은 위 표의 PPO 학습 포획과 별도로 집계했다.

모방 학습의 시범 데이터 오차는 0.474에서 0.012로 줄었지만, 이어진 PPO 학습과 평가에서는 포획이 0건이었다. 이번 결과에서는 막힘 감점을 0.05로 유지하고 PPO 단계 수도 늘리지 않기로 했다. 감점을 높여도 포획 보상이 발생하지 않았고, 모방 초기화에서도 포획 경험이 생기지 않았다. 학습 시드 한 개의 결과라서 더 긴 학습의 효과는 확인하지 못했다.

## 재현 방법

저장소 루트에서 실행한다. 추격 비교는 표준 라이브러리로 동작한다. 원본 거리 표본과 판별 지표는 `artifacts/tag-followup/approach-{dev,holdout}.json`, 최종 PPO 모델·설정·평가는 `artifacts/tag-followup/verified/`에 있다. 아래 예시는 새 폴더에 결과를 쓴다.

```bash
python3 -m simulator.examples.tag_comparison --seeds {11000..11009} --output artifacts/tag-followup-repro/dev.json
python3 -m simulator.examples.tag_comparison --seeds {41000..41009} --output artifacts/tag-followup-repro/holdout.json
```

PPO는 기존 실험과 같은 패키지 버전의 가상환경에서 `OMP_NUM_THREADS=1`로 다음 Python 코드를 실행한다. 각 모델의 `config.json`에 실행 단계, 시드, 학습 포획 횟수, 모델 SHA-256과 모방 설정을 저장한다. [학습 환경](TRAINING.md)

```python
from functools import partial
from pathlib import Path
import json

from simulator.controllers import RuleController
from simulator.environment import default_reward
from simulator.evaluate import run
from simulator.examples.ppo_controller import PPOController
from simulator.examples.tag_reward import double_blocked_penalty
from simulator.examples.train_ppo import train

root = Path('artifacts/tag-followup-repro/ppo')
controllers = {'rule': RuleController}
evaluation = range(21000, 21010)
for label, reward, demos in [('default', default_reward, ()),
                             ('double', double_blocked_penalty, ()),
                             ('imitation', default_reward, range(51000, 51010))]:
    model = train(steps=16384, seed=72, reward_fn=reward,
                  rule_demo_seeds=demos, output=root / label)
    config = json.loads((model.parent / 'config.json').read_text())
    used = set(config['training_episode_seeds']) | set(demos)
    assert used.isdisjoint(evaluation) and used.isdisjoint(range(41000, 41010))
    controllers[label] = partial(PPOController, model, 'tag')
run(seeds=evaluation, controllers=controllers, output=root / 'evaluation.json')
```
