# ChildACT 동작을 캐릭터에 적용하기

[README](../README.md) · [게임 규칙](SIMULATION.md)

## 입력과 실행

사용자가 직접 내려받은 [ChildACT v1](https://zenodo.org/records/14603227)의 ZIP을 사용합니다. 검사한 파일의 MD5는 `d1d6cfe12f0221463280803c8b0eb581`입니다. ZIP에는 원본 영상이 없고 관절 배열 `.npy` 파일 109,835개가 들어 있습니다. 제작 논문은 Sandygulova et al., *ChildACT: Child Action Recognition Dataset in RGB Data*, HRI 2025, DOI `10.1109/HRI61500.2025.10974037`입니다.

```bash
python3 tools/build_childact_motion.py /path/to/ChildACT.zip
python3 -m simulator.server
```

변환기는 Python 표준 라이브러리로 숫자 배열만 읽습니다. pickle을 실행하지 않습니다. 결과는 `simulator/static/motions/childact.local.json`에 저장되며, Git에서 제외합니다. 원본과 파생 데이터를 외부 배포하기 전에는 제공 조건을 따로 확인해야 합니다. 데이터는 원격 서버로 전송하지 않습니다.

## 실제 변환

1. `run`·`jog`·`walk` 폴더만 검사합니다. 비정상적으로 중첩된 폴더는 선택 대상에서 제외합니다.
2. `(1,25,3)`인 단일 검출 대상 프레임을 사용합니다. 관절 순서는 OpenPose BODY_25와 호환되는 것으로 추정합니다. 데이터에 관절 정의 설명서가 없으므로 확정된 메타데이터는 아닙니다.
3. 세 값을 화면상의 x·y·신뢰도로 해석합니다. 낮은 신뢰도의 점을 제외하고 12프레임 이하의 짧은 누락 구간만 선형 보간합니다. 파일명 프레임 번호를 사용하므로 누락 프레임을 단순히 압축해 재생하지 않습니다.
4. 고관절·어깨의 투영 각도와 무릎·팔꿈치의 굽힘 각도를 구하고 평활화합니다. 기본 영상 종횡비 4:3은 가정이며 `--aspect`로 바꿀 수 있습니다.
5. 각 동작에서 관절 변화가 있고 끝 자세가 비슷한 짧은 구간을 골라 64개 표본으로 변환합니다. 끝 자세 차이를 점진적으로 보정해 반복 구간을 닫습니다. 결과에 원본 폴더와 시작·끝 프레임을 기록합니다.
6. 캐릭터 체형에 맞춰 고관절·어깨의 평균 자세를 제거하고 각도 변화량을 조절합니다. 팔꿈치·무릎의 굽힘 방향과 발의 바닥 접촉은 해부학적·시각적 근사입니다.

출력의 `source`와 `assumptions`, 각 `clips`의 원본 프레임 정보를 통해 추적할 수 있습니다. 추출 가능한 구간이 없으면 오류를 내며 임의 모션을 ChildACT 데이터로 표시하지 않습니다. 화면의 기본 동작 대체는 별도 상태로 표시합니다.

## 재현하는 것과 한계

| 항목 | 처리 |
|---|---|
| 관절 각도의 시간에 따른 변화 | 선택한 실제 2차원 기록에서 추출·보간·보정 |
| 캐릭터 크기·관절 굽힘 방향·깊이 방향 | 캐릭터에 맞춘 근사 |
| 재생 주기 | 걷기 1.05초, 조깅 .86초, 달리기 .72초로 선택한 시뮬 값 |
| 원본 FPS·실측 이동 속도 | 확인되지 않았으며 복원하지 않음 |
| m 단위 바닥 이동 경로 | `games.py`가 로봇·벽·다른 아이의 위치로 계산 |
| 실제 어린이의 술래잡기 전략 | 포함하지 않음 |

따라서 이 기능은 **실제 관절 데이터를 참고한 캐릭터 애니메이션**입니다. 완전한 3차원 모션 캡처, 실측 보행 속도나 실제 어린이의 회피 궤적 재현으로 평가해서는 안 됩니다. 캐릭터가 더 자연스럽게 보이더라도 영상 인식 모델의 실제 어린이 대상 성능이 검증되는 것은 아닙니다.
