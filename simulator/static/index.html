내 Python 프로그램과 연결

시뮬레이터 서버와 이 브라우저 탭을 열어 둔 상태로, 저장소 루트에서 AI 프로그램을 실행하세요.

1. 가상 카메라 영상 받기

from simulator.client import SimRobot
import cv2
import numpy as np

robot = SimRobot()
jpeg = robot.camera_frame()
image = cv2.imdecode(
    np.frombuffer(jpeg, np.uint8),
    cv2.IMREAD_COLOR
)
# image를 직접 만든 AI에 입력하세요.

2. AI의 판단 결과로 로봇 제어

# 단위: m/s, rad/s, 초. 양의 회전은 왼쪽.
robot.command_velocity(linear_mps=0.1, seconds=0.5)
robot.command_velocity(angular_rps=1.0, seconds=1.0)
robot.stop()
robot.say("안녕하세요!")

영상 API

GET /api/camera.jpg최신 JPEG 프레임
GET /api/camera/stream.mjpgOpenCV로 읽는 MJPEG
GET /api/camera/meta프레임 번호 · 촬영 시각

카메라는 이 탭에서 렌더링합니다. 탭이 닫히거나 백그라운드에서 렌더링이 중단되면 영상 API가 503을 반환합니다. 가상 인물은 단순 3D 모델이므로 실제 사람 영상으로 학습한 모델의 인식 성능은 별도로 확인해야 합니다. 상세 API는 simulator/README.md를 확인하세요.
