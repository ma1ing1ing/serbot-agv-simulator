# 실험 후보

2026-11-22에 첫 실험 7건을 마쳤다. 아래 세 건은 다음 실험 후보이며, 기준 제어기는 `rule`이다. [기존 실험 조건과 결과](../../docs/TAG_EXPERIMENTS.md)

## 1. 첫 포획까지 거리가 줄어드는 구간 확인

시드 11000·11008에서 마지막 표적 전환부터 첫 포획까지 각각 15.54초·14.20초가 걸렸다. 두 판 모두 첫 포획 당시 표적 중심이 벽에서 약 0.25m 떨어져 있었다. 다른 개발 시드에서도 이 경향이 나타나는지 확인한다.

- `rule`로 기존 개발 시드 11000–11009를 재현한다. 조건은 아이 5명, `open`, `oracle`, 30초, 제어 간격 0.1초다.
- 완료 조건은 시드별로 첫 포획 시각, 마지막 전환부터 걸린 시간, 같은 표적을 추격하는 동안의 거리 변화, 첫 포획 지점에서 가장 가까운 벽까지의 거리를 기록하는 것이다. 무포획 판은 시간 초과로 표시해 집계에 포함한다.

## 2. 접근 속도를 반영한 표적 선택 비교

가까운 후보 중 최근 1초 동안 로봇과의 거리가 줄어든 대상을 우선하는 개인 제어기를 `rule`과 비교한다. 표적 선택만 바꾸고 현재 위치 조준, 전환 기준 0.3m, 주행 설정은 두 제어기에서 같게 둔다.

- 같은 개발 시드에서 첫 포획 시간과 총포획 수를 함께 비교한다. 무포획 판 수, 포획 비율·전원 포획률, 근접 단계·회전 변화·막힘도 기록한다.
- 완료 조건은 시드별 비교를 바탕으로 첫 포획을 앞당겼을 때 총포획 수와 주행 지표가 어떻게 달라지는지 판단하는 것이다. 후보를 고정한 뒤 기존 개발·평가 및 학습에 쓰지 않은 새 시드에서 `rule`과 다시 비교해 채택 여부를 기록한다.

## 3. PPO 학습 중 포획 보상 발생 횟수 확인

기존 두 PPO 모델의 최종 10판은 모두 포획 0건이었다. 학습 중 막힘은 각각 72회·70회였지만 포획 보상을 받은 횟수는 기록되지 않았다. 다음 학습에서는 먼저 기존 설정을 재현해 이 값을 측정한다.

- 완료 조건은 보상 설정별로 학습 에피소드 수, 포획 이벤트 수, 한 번 이상 포획한 에피소드 수를 기록하고 평가 결과와 대조하는 것이다.
- 학습 중에도 포획이 드물면 `rule`의 추격 행동을 학습 시작점으로 사용하는 실험을 우선한다. 학습 중에는 포획하는데 평가에서만 0건이면, 같은 저장 모델과 같은 평가 시드에서 행동 샘플링과 결정적 행동 선택을 비교한다. 이 진단 결과를 바탕으로 학습량·막힘 감점 조정 여부를 정한다.
